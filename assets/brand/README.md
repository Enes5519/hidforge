# hidforge brand

**Mark:** a mouse whose button split runs down into a keyhole — hidforge unlocks your device.

## Files

| File | Use |
|---|---|
| `hidforge-horizontal.svg` | Primary logo (light backgrounds) |
| `hidforge-horizontal-reversed.svg` | Primary logo on Forest / dark backgrounds |
| `hidforge-stacked.svg` | Square-ish spaces |
| `hidforge-mark.svg` | Symbol alone, 48 px and up |
| `hidforge-mark-small.svg` | Symbol alone, below 48 px (wider split, bigger keyhole) |
| `hidforge-mark-app-icon.svg` / `-small-app-icon.svg` | App icon (Forest tile, amber keyhole) |
| `hidforge-wordmark.svg` | Name alone |
| `*-black.svg`, `*-white.svg` | One-colour print, engraving, overlays |
| `*-tinted.svg` | `currentColor` fill, for UI that tints the mark |
| `icons/` | Linux hicolor PNGs (16–32 px use the small cut) + scalable SVG |

The wordmark is Fira Sans SemiBold (SIL OFL), converted to outlines. No font is needed to show the logo.

## Colours (taken from the app theme)

| Name | HEX | Role |
|---|---|---|
| Forest | `#182825` | Wordmark, app-icon tile, dark backgrounds |
| Green | `#205b4e` | Symbol on light backgrounds |
| Paper | `#f5f7ef` | Symbol and wordmark on dark backgrounds |
| Amber | `#ffc48e` | Keyhole light, only on dark backgrounds |

## Rules

- **Clear space:** keep space around the logo at least as wide as the keyhole circle (about 1/6 of the symbol height).
- **Minimum size:** horizontal logo 96 px wide; symbol 16 px (use the small cut).
- **Backgrounds:** Paper, white or Forest. On photos, use the one-colour white or black version.
- **Don't:** recolour outside the palette, put amber on light backgrounds, stretch or rotate it, add shadows or gradients, or rebuild the wordmark in another font.
